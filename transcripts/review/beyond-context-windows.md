### B) SYNTHESIS SCRIPT

The context window is a physical constraint. Even for models that can ingest two million tokens, long-form documents like regulatory archives or multi-chapter manuscripts eventually exceed what a model can hold in a single pass. The standard workarounds are all compromises. Chunking loses coherence. Summarization loses detail. Traditional RAG relies on pre-selected fragments that rob the model of its ability to navigate the document structure itself.

The Recursive Language Model pattern, or RLM, shifts this dynamic entirely. Instead of feeding a document into a model, you treat that document as an interactive environment. You aren't asking the model to read the text; you are providing an interface for it to query the text.

I built the rlm-mcp server to move this idea into production. It operates as a Model Context Protocol server, which means it provides a standardized way for tools like Claude Code or Cursor to interact with your data.

When you load a document into an RLM session, the server doesn't just hold the file. It provides an indexing and search layer. The model can perform BM25 keyword searches, use regex matching, or peek at specific spans of text. Crucially, the model is in control. It decides what to search, when to read a section in full, and how to chunk the data. It works exactly like a human researcher scanning a paper.

Provenance is the backbone of this architecture. Every output generated by the model is logged with its source—down to the exact character ranges in the document. This makes the model's outputs auditable and defensible. You never have to guess where an insight came from.

This system is built for heavy-duty use. It handles concurrent sessions with per-session locks, manages memory usage with smart semaphores, and features an optimized BM25 index that delivers sub-second searches with reload times under one hundred milliseconds. By separating the intelligence of the model from the storage of your data, you get the performance of a high-end search engine with the reasoning depth of a modern LLM.
